SECTION 01 · 질문

1총알이 벽에 맞았는지 매 프레임 어떻게 확인하나

게임 오브젝트는 대개 복잡한 메시(Mesh)다. 메시의 정확한 삼각형 단위로 충돌을 매 프레임 계산하면 너무 느리다.

그래서 실제로는 충돌 감지 전용으로 단순화된 도형(Collision Shape)을 따로 두고, 그 단순한 도형끼리 겹쳤는지를 계산한다. 언리얼 에디터에서 메시에 캡슐·박스 모양의 초록색 콜리전이 따로 붙어있는 게 바로 이거다.

SECTION 02 · 공식

2구체 충돌 · AABB 충돌

구체(Sphere) — 가장 싸고 단순한 판정

겹침 여부 = Distance(CenterA, CenterB) <= RadiusA + RadiusB

bool IsSphereOverlapping(...)
{
    float DistSquared = FVector::DistSquared(CenterA, CenterB);   // sqrt 생략
    float RadiusSum = RadiusA + RadiusB;
    return DistSquared <= RadiusSum * RadiusSum;
}

AABB(Axis-Aligned Bounding Box)

bool IsAABBOverlapping(const FAABB& A, const FAABB& B)
{
    // 세 축 모두 겹쳐야 전체가 겹친 것
    bool bOverlapX = A.Min.X <= B.Max.X && A.Max.X >= B.Min.X;
    bool bOverlapY = A.Min.Y <= B.Max.Y && A.Max.Y >= B.Min.Y;
    bool bOverlapZ = A.Min.Z <= B.Max.Z && A.Max.Z >= B.Min.Z;
    return bOverlapX && bOverlapY && bOverlapZ;
}

핵심: 3차원 판정을 축 3개의 독립적인 1차원 겹침 판정으로 쪼갠다. 한 축이라도 안 겹치면 절대 겹칠 수 없다. AABB는 회전을 반영 못 해서 1차 필터링용으로 많이 쓰인다.

SECTION 04 · 최적화

4브로드 페이즈 vs 내로우 페이즈

오브젝트 1,000개면 모든 쌍(약 50만 쌍)을 정밀 검사하는 건 너무 비싸다.

단계목적특징
브로드 페이즈겹칠 가능성 있는 쌍을 빠르게 걸러냄AABB처럼 싸고 단순한 도형, 공간 분할(그리드, BVH)
내로우 페이즈브로드 페이즈 통과 쌍만 정밀 검사실제 메시 형태, 정확한 충돌 지점·법선까지 계산
1000개 오브젝트
↓
브로드 페이즈AABB로 대략 겹치는 쌍만 추림 (예: 50쌍)
↓
내로우 페이즈그 50쌍만 정밀 충돌 검사 (실제 메시/캡슐 기준)
↓
실제 충돌 이벤트 발생

싼 연산으로 대부분을 걸러내고, 비싼 연산은 살아남은 소수에만 적용한다. 언리얼 물리 엔진(Chaos)도 내부적으로 이 2단계 구조를 쓴다.

SECTION 05 · 규칙

5콜리전 채널 — "누구와 부딪힐 것인가"

// 총알은 Pawn과는 Overlap(겹침만 감지), WorldStatic과는 Block(막힘)
Projectile->GetCollisionComponent()->SetCollisionResponseToChannel(
    ECC_Pawn, ECollisionResponse::ECR_Overlap);
Projectile->GetCollisionComponent()->SetCollisionResponseToChannel(
    ECC_WorldStatic, ECollisionResponse::ECR_Block);

Ignore로 설정된 채널 쌍은 브로드 페이즈 단계에서부터 검사 대상에서 제외된다 — 정확성뿐 아니라 성능에도 직접 영향을 준다.

SECTION 06 · 함정

6터널링(Tunneling)과 CCD

한 프레임에 이동하는 거리가 벽 두께보다 크면, 총알이 벽 안팎 어디에도 걸리지 않고 통과해버린다.

프레임 N:   ● (벽 앞)         ┃벽┃
프레임 N+1:                   ┃벽┃         ● (벽 뒤, 통과해버림!)

해결책: 연속 충돌 감지(CCD) — 이전 위치에서 현재 위치까지 경로 전체를 스윕(Sweep) 검사한다.

FHitResult HitResult;
bool bHit = GetWorld()->SweepSingleByChannel(
    HitResult, PreviousLocation, NewLocation, FQuat::Identity,
    ECC_WorldStatic, FCollisionShape::MakeSphere(ProjectileRadius));
if (bHit) { NewLocation = HitResult.Location; OnProjectileHit(HitResult); }

언리얼 ProjectileMovementComponent의 bSweepCollision 옵션이 이 스위치다. 스윕은 비용이 크므로 빠른 오브젝트에만 선택적으로 켠다.
