Part 3 · 좌표계와 회전

Look-At, 회전값 구하기

터렛이 플레이어를 바라보게 하려면 방향 벡터를 회전값으로 바꿔야 한다. 타겟을 슬라이더로 움직여 atan2가 왜 atan보다 안전한지 직접 확인한다.

🎯 atan2가 핵심
🧩 선수지식 1~5강
⏱️ 약 18분
SECTION 01 · 질문

1터렛이 플레이어를 바라보게 하고 싶다

방향 벡터는 쉽게 구했다 — PlayerLocation - TurretLocation. 그런데 이걸 그대로 회전(FRotator)에 넣을 수는 없다.

FVector Direction = (PlayerLocation - TurretLocation).GetSafeNormal();
// Turret->SetActorRotation(???);  ← FVector를 어떻게 회전으로?

FRotator LookAtRotation = UKismetMathLibrary::FindLookAtRotation(TurretLocation, PlayerLocation);
Turret->SetActorRotation(LookAtRotation);

이 강의는 FindLookAtRotation이 내부적으로 뭘 계산하는지, 왜 방향 벡터 하나로 회전값이 결정되는지를 파본다.

SECTION 02 · 개념

2Rotator vs Quaternion, 그리고 Yaw/Pitch 공식

FRotator: Pitch(상하)·Yaw(좌우)·Roll(기울임) 세 각도. 사람이 이해하기 쉬움.

FQuat: 4개 숫자(X,Y,Z,W)로 표현. 보간·합성에 안정적이고 짐벌락 없음.

핵심: 방향 벡터를 알면, "그 방향을 바라보는 회전"은 유일하게 하나로 정해진다 (Roll=0 전제).

Yaw   = atan2(Direction.Y, Direction.X)
Pitch = atan2(Direction.Z, sqrt(Direction.X² + Direction.Y²))
Roll  = 0  // 방향만으로는 결정 안 됨, 보통 고정

atan2는 두 값의 부호를 같이 받아서 사분면 전체(-180°~180°)를 올바르게 구분한다. 단순 Y/X 비율(atan)만으로는 사분면을 구분 못 한다.

SECTION 03 · 핵심 · 직접 돌려보기

3터렛 조준 시뮬레이터 — atan vs atan2

타겟을 슬라이더로 움직여보자. 점선은 실제 방향, 화살표는 계산된 회전. atan(Y/X) 모드로 바꿔서 왼쪽으로 타겟을 옮기면 무슨 일이 생기는지 확인해보자.

SECTION 04 · 내부 동작

4FindLookAtRotation이 하는 일

FRotator FindLookAtRotation(const FVector& Start, const FVector& Target)
{
    FVector Direction = (Target - Start).GetSafeNormal();
    return Direction.Rotation();   // 내부적으로 atan2 기반 계산
}

딱 두 단계다: (1) 변위 벡터를 구해 정규화 — 방향만 남긴다(1강). (2) 그 방향을 atan2 기반으로 회전값으로 변환(이 강의). 새로운 수학이 아니라 지금까지 배운 걸 조합한 것뿐이다.

내적/외적으로 회전 구하기 (Quaternion 기준)

회전각(θ)  = acos(dot(CurrentForward, TargetDirection))   // 내적으로 각도
회전축(Axis) = cross(CurrentForward, TargetDirection)      // 외적으로 축

현재 방향에서 목표까지 얼마나, 어느 축으로 돌아야 하는지 직접 구하는 방식이라 부드러운 회전 보간에 자연스럽게 이어진다.

SECTION 05 · 실전

5지상 캐릭터의 Pitch 고정 · 터렛 시야각+Look-At

FRotator LookAtRotation = UKismetMathLibrary::FindLookAtRotation(GetActorLocation(), TargetLocation);
LookAtRotation.Pitch = 0.0f;   // 몸통은 좌우로만 회전
LookAtRotation.Roll = 0.0f;
SetActorRotation(LookAtRotation);

시선 방향을 몸통에 그대로 적용하면 위/아래를 볼 때 몸이 이상하게 숙여진다. 몸통엔 Yaw만, 카메라·머리 본엔 Pitch까지 반영한다.

void ATurret::TrackTarget(AActor* Target, float DeltaTime)
{
    FVector ToTarget = (Target->GetActorLocation() - GetActorLocation()).GetSafeNormal();
    float DotResult = FVector::DotProduct(GetActorForwardVector(), ToTarget);   // 3강: 시야각 체크
    if (DotResult < TrackingCosLimit) return;

    FRotator DesiredRotation = UKismetMathLibrary::FindLookAtRotation(GetActorLocation(), Target->GetActorLocation());
    DesiredRotation.Pitch = 0.0f;
    SetActorRotation(FMath::RInterpTo(GetActorRotation(), DesiredRotation, DeltaTime, 5.0f));   // 부드러운 회전
}

벡터(방향)·내적(시야각)·Look-At(회전)이 한 함수 안에서 자연스럽게 합쳐진다.
