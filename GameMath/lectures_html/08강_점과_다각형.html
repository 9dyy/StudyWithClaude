점과 다각형

오각형 안전 구역에 클릭 지점이 들어왔는지 어떻게 판정할까. 오목한 다각형 위를 직접 클릭해서 외적 부호법과 Ray Casting의 차이를 확인한다.

SECTION 01 · 질문

1클릭한 지점이 이 구역 안에 있는지 어떻게 판정하나

"오각형 모양의 안전 구역 안에 마우스 클릭 지점이 들어왔는지" 판정해야 한다. 7강의 AABB/구체로는 임의의 다각형을 표현할 수 없다.

bool bIsInside = IsPointInPolygon(ClickedPoint, ZoneVertices);

스킬 범위 표시, 존(Zone) 감지, 미니맵 영역 클릭 판정처럼 사각형/원으로 안 떨어지는 영역을 다룰 때 자주 나온다. 대표적인 두 가지 방법 — 외적 부호 판정과 Ray Casting — 을 다룬다.

SECTION 02 · 볼록 다각형

2외적 부호 판정 (볼록 다각형)

다각형의 각 변에 대해, 점이 그 변의 "안쪽"에 있는지를 외적의 부호(4강)로 확인한다. 모든 변에서 부호가 일관되면 내부.

for (int32 i = 0; i < NumVertices; ++i)
{
    FVector2D Edge = Vertices[(i + 1) % NumVertices] - Vertices[i];
    FVector2D ToPoint = Point - Vertices[i];
    float Cross = Edge.X * ToPoint.Y - Edge.Y * ToPoint.X;   // 2D 외적 (Z 성분만)
    if (Cross > 0.0f) bHasPositive = true;
    if (Cross < 0.0f) bHasNegative = true;
}
return !(bHasPositive && bHasNegative);   // 한쪽으로만 나오면 내부

이 방법은 볼록 다각형에서만 정확하다. 오목한 부분이 있으면 변마다 "안쪽"의 의미가 뒤틀려서 부호 비교가 깨진다.

SECTION 03 · 일반해

3Ray Casting — 오목 다각형까지 다루기

점에서 임의의 방향(오른쪽 무한대)으로 광선을 쏴서, 다각형의 변과 몇 번 교차하는지 센다. 홀수면 내부, 짝수면 외부.

bool bYCrosses = ((Vi.Y > Point.Y) != (Vj.Y > Point.Y));
if (bYCrosses) {
    float IntersectX = Vi.X + (Point.Y - Vi.Y) * (Vj.X - Vi.X) / (Vj.Y - Vi.Y);
    if (Point.X < IntersectX) bInside = !bInside;   // 교차마다 안/밖 뒤집기
}

점에서 뻗은 광선이 경계를 넘나들 때마다 안/밖이 뒤집힌다는 사실은 볼록/오목과 무관하게 항상 성립한다 — 그래서 일반적으로 적용된다.

SECTION 05 · 참고

5Winding Number — 개념만 짚고 가기

판정할 점을 중심으로, 다각형 경계가 점 주위를 몇 바퀴 감았는지 계산한다. 0이면 밖, 0이 아니면 안.

Ray Casting은 "교차 횟수의 홀짝"을, Winding Number는 "각도 변화의 총합"을 본다. 자기 자신과 교차하는 별 모양 다각형에서 더 정교하다 — 일반 존 판정에는 Ray Casting으로 충분하다.

3D → 2D 투영해서 판정

bool IsActorInZone(AActor* Actor, const TArray<FVector2D>& ZoneVertices2D)
{
    FVector Location3D = Actor->GetActorLocation();
    FVector2D Location2D = FVector2D(Location3D.X, Location3D.Y);   // Z 무시, XY만 투영
    return IsPointInPolygonRayCast(Location2D, ZoneVertices2D);
}
