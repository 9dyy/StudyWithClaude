내적 (Dot Product)

몬스터가 플레이어를 "보고 있는지" 어떻게 판정할까. 슬라이더로 각도와 시야각을 직접 움직이며 내적이 코사인과 어떻게 연결되는지 확인한다.

📐 내적 = cos(θ)
🧩 선수지식 1·2강
⏱️ 약 18분
SECTION 01 · 질문

1"적이 내 시야 안에 있는지" 어떻게 판단하나

"플레이어가 몬스터의 정면 90도 시야각 안에 들어오면 발견한다." 거리는 FVector::Dist로 되는데, 각도는?

FVector ToPlayer = (PlayerLocation - MonsterLocation).GetSafeNormal();
FVector MonsterForward = Monster->GetActorForwardVector();
float DotResult = FVector::DotProduct(MonsterForward, ToPlayer);
// DotResult가 클수록(1에 가까울수록) 정면에 가깝다

실무에서는 atan2나 삼각함수 대신 훨씬 싸고 간단한 내적(Dot Product)을 쓴다. 벡터 두 개를 내적하면 그 사이 각도와 직결된 숫자 하나가 바로 나온다.

SECTION 02 · 정의

2내적의 정의 — 계산은 아주 단순하다

A · B = A.X * B.X + A.Y * B.Y + A.Z * B.Z

FVector A = FVector(1, 0, 0);
FVector B = FVector(0.7071f, 0.7071f, 0);   // 45도 방향 단위 벡터
float Dot = FVector::DotProduct(A, B);   // = 0.7071

결과는 스칼라 하나다. 벡터끼리 계산했는데 숫자 하나가 나온다는 게 특징이다.

A · B = |A| * |B| * cos(θ)

A, B가 둘 다 정규화된 단위 벡터라면 (|A|=|B|=1):

A · B = cos(θ)

내적 결과각도(대략)의미
1.00°완전히 같은 방향 (정면)
0.745°대각선 정도
0.090°완전히 수직
-0.7135°거의 반대 방향
-1.0180°정반대 방향
SECTION 03 · 핵심 · 직접 돌려보기

3시야각(FOV) 판정 시뮬레이터

타겟 각도와 시야각(HalfFOV)을 슬라이더로 움직여서 내적 값과 판정 결과가 어떻게 바뀌는지 확인해보자.

타겟 각도 θ 40°
시야각 절반 (HalfFOV) 45°
Dot(Forward, ToTarget)0.766
cos(HalfFOV) 기준값0.707
시야 안에 있음 ✓

코사인은 각도가 커질수록 작아진다. 그래서 "HalfFOV 이내"는 Dot >= cos(HalfFOV)로 판정한다 — 부등호 방향이 직관과 반대로 보이기 쉬운 지점이다.

SECTION 04 · 또 다른 얼굴

4내적의 또 다른 얼굴 — 투영(Projection)

"한 벡터가 다른 벡터 방향으로 얼마나 나아갔는가"도 내적으로 구한다. 경사면을 오를 때 이동 입력을 경사면 방향으로 투영하는 게 대표 예다.

투영된 길이 = A · B_hat     // B_hat은 B의 정규화된 단위 벡터

FVector InputDir = FVector(1, 0, 0);
FVector SlopeDir = SlopeNormal.GetSafeNormal();
float ProjectedLength = FVector::DotProduct(InputDir, SlopeDir);
FVector ProjectedMovement = SlopeDir * ProjectedLength;

각도 판정과 투영은 같은 공식(A · B_hat)의 두 가지 해석일 뿐이다 — "코사인 값으로 볼 것인가", "그림자 길이로 볼 것인가"의 차이다.

SECTION 05 · 실전 활용

5락온 우선순위 · 백어택 판정

락온(Lock-On) — 정면에 가장 가까운 적 고르기

AActor* FindBestLockOnTarget(...)
{
    float BestDot = -1.0f;
    for (AActor* Candidate : Candidates)
    {
        float Dot = FVector::DotProduct(Forward, ToCandidate);
        if (Dot > BestDot) { BestDot = Dot; BestTarget = Candidate; }  // 내적 최대 = 정면에 가장 가까움
    }
    return BestTarget;
}

백어택(Backstab) — 등 뒤 판정

float DotResult = FVector::DotProduct(EnemyForward, EnemyToAttacker);
const float BackstabThreshold = -0.5f;   // 대략 후방 120도
return DotResult <= BackstabThreshold;   // 반대 방향에 가까우면 등 뒤
