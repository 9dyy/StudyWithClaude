외적 (Cross Product)

내적은 좌/우를 못 구분한다. 슬라이더로 타겟을 돌려보며 외적의 부호가 어떻게 왼쪽/오른쪽을 갈라내는지 직접 확인한다.

🧭 부호로 좌/우 판정
🧩 선수지식 1~3강
⏱️ 약 18분
SECTION 01 · 질문

1"적이 내 왼쪽에 있는지 오른쪽에 있는지" 어떻게 판단하나

내적은 "얼마나 같은 방향인가"를 알려준다. 하지만 "왼쪽인가 오른쪽인가"엔 답을 못 준다 — 내적은 대칭(A·B == B·A)이라 방향의 치우침을 모른다.

FVector ToEnemy = (EnemyLocation - MyLocation).GetSafeNormal();
FVector MyForward = GetActorForwardVector();
FVector CrossResult = FVector::CrossProduct(MyForward, ToEnemy);
// CrossResult.Z가 양수면 오른쪽, 음수면 왼쪽 (언리얼 좌표계 기준)

외적은 각도 대신 "어느 쪽으로 꺾여 있는가"와 "두 벡터에 동시에 수직인 방향"을 알려준다.

SECTION 02 · 정의

2외적의 정의 — 결과가 벡터다

A × B = (A.Y*B.Z - A.Z*B.Y,  A.Z*B.X - A.X*B.Z,  A.X*B.Y - A.Y*B.X)

FVector A = FVector(1, 0, 0);
FVector B = FVector(0, 1, 0);
FVector Result = FVector::CrossProduct(A, B);   // (0, 0, 1)

내적이 스칼라 하나를 뱉는 것과 달리, 외적은 벡터를 뱉는다 — 가장 먼저 기억할 차이. 결과는 두 벡터 모두에 수직인 법선 벡터(Normal Vector)다.

SECTION 03 · 순서 주의

3외적의 순서가 중요하다

A × B = -(B × A)

FVector Forward1 = FVector::CrossProduct(A, B);   // 예: (0,0,1)
FVector Forward2 = FVector::CrossProduct(B, A);   // (0,0,-1) — 정반대

이게 좌/우 판정의 핵심이다. 순서를 바꾸면 부호가 뒤집히므로, 프로젝트 안에서 순서를 일관되게 정해놓고 써야 한다.

|A × B| = |A| * |B| * sin(θ)

이 값은 A와 B가 만드는 평행사변형의 넓이와 같다. 두 벡터가 평행하면(θ=0 또는 180°) sin(θ)=0이라 외적 결과가 0벡터가 된다 — "평행한 두 벡터는 법선을 정의할 수 없다"는 뜻.

SECTION 04 · 핵심 · 직접 돌려보기

4좌/우 판정 시뮬레이터

타겟 각도를 움직여서 Cross.Z 부호가 어떻게 왼쪽/오른쪽을 갈라내는지 확인해보자. (양수 각도 = 오른쪽으로 회전)

타겟 각도 θ 60°
Cross(Forward, ToTarget).Z0.866
Dot(Forward, ToTarget) = cos(θ)0.500
오른쪽 →

Cross.Z와 Dot이 동시에 뜨는 이유: 외적의 크기는 sin(θ), 내적은 cos(θ)다. 방향의 크기(내적)와 치우침(외적)은 서로 다른 정보라 둘 다 필요할 때가 많다.

SECTION 05 · 실전 조합

5법선 벡터로 "걸을 수 있는 경사인지" 판정

바닥 삼각형의 두 변을 외적하면 법선 벡터가 나온다. 이 법선과 월드 Up 벡터를 내적(3강)하면 바닥 기울기의 코사인이 된다 — 외적과 내적이 손을 잡는 지점.

bool IsFloorWalkable(const FVector& FloorNormal, float MaxWalkableAngleDegrees)
{
    // 법선이 위(Up)를 향할수록 평평한 바닥, 옆을 향할수록 가파른 경사/벽
    float DotWithUp = FVector::DotProduct(FloorNormal.GetSafeNormal(), FVector::UpVector);
    float MaxCos = FMath::Cos(FMath::DegreesToRadians(MaxWalkableAngleDegrees));
    return DotWithUp >= MaxCos;   // 3강의 시야각 판정과 정확히 같은 형태
}
SECTION 06 · 실전 활용

6좌우 회피(Dodge) 방향 결정

FVector GetDodgeDirection(AActor* Attacker) const
{
    FVector AttackerForward = Attacker->GetActorForwardVector();
    FVector AttackerToMe = (GetActorLocation() - Attacker->GetActorLocation()).GetSafeNormal();
    FVector Cross = FVector::CrossProduct(AttackerForward, AttackerToMe);

    // 공격자 기준 내가 오른쪽에 있으면, 더 바깥쪽인 오른쪽으로 회피
    return (Cross.Z >= 0.0f) ? GetActorRightVector() : -GetActorRightVector();
}
