SECTION 01 · 쓰는 법

1이 문제집을 쓰는 법

각 문항은 Q(질문) → A(모범 답변) → 🔑(30초 키워드) → 연결(같이 묻기 쉬운 문항) 순으로 구성했다. 카드를 클릭해서 펼치기 전에 먼저 스스로 답을 떠올려보고, 펼친 뒤 맞았는지 확인해라.

답변을 다 확인했으면 카드 아래 알았음 / 애매함 / 모르겠음 버튼으로 자기 상태를 기록한다. 이 기록은 브라우저에 저장되고, 아래 "면접 시뮬레이터"에서도 똑같이 쌓인다.

4면접 직전 30초 체크 — 키워드만

주제한 줄 요약
static 4형태지역 static(1회 초기화) / 파일스코프(내부링키지) / 멤버변수(공유) / 멤버함수(this 없음) — 전부 데이터·코드 영역, 힙 아님

RAII생성자=획득, 소멸자=해제 → 스마트 포인터의 원리
배열 vs LinkedList이론은 LinkedList 삽입 유리, 실측은 캐시 지역성 때문에 배열이 이기는 경우 많음
Stack/QueueLIFO=최근 것 먼저(Undo), FIFO=순서 보장(커맨드 큐), BFS=Queue·DFS=Stack

SECTION 05 · 마무리

5마지막 조언

  • 1. 암송하지 마라. 키워드를 기억하고 자기 말로. 외운 티 나면 감점.
  • 2. 모르면 "모릅니다"가 낫다. 아는 척하다 꼬리질문에서 무너지는 게 최악.
  • 3. 게임 경험과 엮어라. "언리얼에서 ~할 때 이게 문제였다"는 답이 신입한테 가장 강력하다.
  • 4. 막히는 주제는 카드에 적힌 출처 강의로 돌아가라. 각 강의 "면접에서 나오면" 섹션만 모아 읽어도 좋다.
