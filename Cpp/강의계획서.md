# C++ · 자료구조 · 디자인 패턴 강의 계획서

> **수강생:** 언리얼 C++ 클라이언트 개발 신입 (DB/Network/OS는 별도 시리즈로 진행 중)
> **목표:** 이직 면접에서 나오는 C++ 문법·자료구조·디자인 패턴 질문에 "정의만 아는 사람" 말고 "왜 그런지 아는 사람"으로 답하는 수준까지.
> **분량:** 본강 12강 + 보너스 1강

---

## 이 강의가 지향하는 것

DB/Network/OS 세 시리즈에 안 들어가는, 그러나 실제로 면접에서 자주 나오는 세 영역 — **C++ 언어 문법, 기본 자료구조, 게임에서 자주 쓰는 디자인 패턴** — 을 한 과목으로 묶는다. 대학 알고리즘 수업처럼 "빅오 표기법을 서술하시오"를 외우는 강의가 아니라, **언리얼 C++로 게임을 만드는 사람이 이 개념을 실제로 어디서 마주치는지**부터 붙여서 설명한다.

예시:
- "`static` 멤버 함수는 왜 `this`가 없지?" → 정적 바인딩과 클래스 vs 인스턴스
- "`Cast<AEnemy>(Actor)`는 내부에서 뭘 하는 거지?" → dynamic_cast와 RTTI
- "총알을 매 프레임 `new`/`delete` 하면 왜 프레임 드랍이 오지?" → Object Pooling
- "HP가 바뀔 때마다 UI가 어떻게 자동으로 갱신되지?" → Observer Pattern과 언리얼 Delegate

각 강의는 **"이걸 모르면 면접에서 답 못하는 것"** 과 **"이걸 모르면 코드 짤 때 헛발질하는 것"** 을 모두 다룬다.

## 학습 방식

- 각 강의는 별도 `.md` 파일로 `lectures/` 폴더에 둔다.
- 모든 코드 예제는 **C++ 표준 또는 언리얼 API**로 작성한다. (Python, Java, C# X)
- 강의 끝에는 **면접 질문 5개 이상**과 **간단한 셀프 체크**를 둔다.
- 한 강의 분량: 읽는 데 15~25분.

## 커리큘럼 (총 12강 + 보너스)

### Part 1. C++ 문법 심화 — "면접에서 진짜 많이 물어보는 문법"

| 강의 | 제목 | 핵심 키워드 |
|------|------|------------|
| 1강 | static의 여러 얼굴 | 정적 멤버 변수/함수, 지역 static, 초기화 시점, 클래스 vs 인스턴스 |
| 2강 | C++ 캐스팅 4형제 | static_cast, dynamic_cast, reinterpret_cast, const_cast, C-style cast와의 차이, 언리얼 `Cast<T>` |
| 3강 | 생성자·소멸자와 RAII | 초기화 리스트, 암시적 생성자, 소멸자 호출 시점, 스마트 포인터로 이어지는 이유 |

### Part 2. 자료구조 기본기 — "왜 이 자료구조를 쓰는가"

| 강의 | 제목 | 핵심 키워드 |
|------|------|------------|
| 4강 | 배열 vs LinkedList | 삽입/삭제/탐색 시간복잡도, 캐시 지역성, `TArray` vs `TLinkedList` |
| 5강 | Stack과 Queue | LIFO/FIFO, Undo 스택, BFS 커맨드 큐, 언리얼에서의 실제 쓰임 |
| 6강 | 해시맵과 트리 맛보기 | `TMap` 내부 동작, 언제 배열 대신 맵을 쓰나, 트리 기반 탐색 개념 |

### Part 3. 게임에서 자주 쓰는 디자인 패턴 — "패턴 이름보다 왜 쓰는지"

| 강의 | 제목 | 핵심 키워드 |
|------|------|------------|
| 7강 | Object Pooling | 매 프레임 new/delete의 비용, GC/메모리 단편화, 총알·이펙트 풀링 |
| 8강 | Observer Pattern | 느슨한 결합, 언리얼 Delegate/Event, HP 변화 → UI 자동 갱신 |
| 9강 | Singleton과 Factory | 언리얼 GameInstance/Subsystem, 팩토리로 액터 생성하는 이유 |
| 10강 | State Pattern | 캐릭터 상태 머신, if-else 지옥을 패턴으로 정리하는 법 |

### Part 4. 실전 보강 — AI 면접 공통역량 점검에서 드러난 빈틈

Part 1~3 작성 이후, 실제 면접 질문 분석 과정에서 커버리지가 비어 있던 두 영역을 추가했다. 스마트 포인터는 3강 RAII의 직계 후속이고, 정렬/시간복잡도는 4~6강 자료구조와 같은 결이라 별도 과목으로 쪼개지 않고 이 시리즈에 이어 붙였다.

| 강의 | 제목 | 핵심 키워드 |
|------|------|------------|
| 11강 | 스마트 포인터: unique_ptr, shared_ptr, weak_ptr | 소유권, 참조 카운트, 순환 참조, move semantics, Rule of 3/5 |
| 12강 | 정렬 알고리즘과 시간복잡도 | Big-O, 버블/삽입/퀵/머지 정렬, 분할정복, 안정 정렬, TArray::Sort |
