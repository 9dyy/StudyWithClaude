SECTION 01 · 만약에

1이 코드가 그냥 되면 큰일이다

게임 코드가 다른 프로세스(카톡, 크롬)의 메모리를 마음대로 읽을 수 있다면? 비밀번호도 메시지도 다 털린다.

void Hack() {
    // 다른 프로세스(카톡)의 메모리를 통째로 읽기
    char* Other = (char*)0x12345678;
    char Stolen = *Other;   // 이게 되면 안 된다!
}

CPU가 차원에서 이걸 막는다. 그 장치가 유저 모드 / 커널 모드. 아래에서 직접 시도해보자. ↓

SECTION 03 · 비용 실험

3시스템 콜은 비싸다 — mode switch

시스템 콜은 유저→커널로 넘어가는 mode switch를 동반한다(레지스터 저장, 커널 스택 전환, 인자 검증). 같은 데이터를 쓰는데 시스템 콜 횟수만 다르게 해보자.

📦 한 번에 쓰기
syscall 1번
🐢 한 줄씩 10만 번
syscall 100,000번

엔진들이 메모리 풀·배치 I/O·버퍼링을 쓰는 이유가 이것 — 시스템 콜 횟수를 줄이려고. UE_LOG를 디버그 빌드에서 미친 듯이 찍으면 느려지는 것도 콘솔 출력이 시스템 콜이라서다.
