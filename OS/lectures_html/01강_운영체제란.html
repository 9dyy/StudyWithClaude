SECTION 02 · OS의 정체

  
2OS가 하는 두 가지 일

  
운영체제는 결국 이 둘로 요약된다. 첫째 카드의 버튼을 눌러 "자원 관리"가 무슨 뜻인지 보자.

② 하드웨어 추상화

      
모니터가 4K든 1080p든, GPU가 뭐든 — 게임은 "텍스트 출력해줘" 한 줄만 부르면 된다. OS가 하드웨어 차이를 다 통역한다.

SECTION 04 · 정리

  
4언리얼 함수 → OS API → 하드웨어
